# Airbnb Clone - Development Guidelines

## Goal

Build an original desktop-only recreation of the provided Airbnb listing reference for the PlayPower Labs take-home assignment.

## Priorities

1. Visual fidelity
2. Behavioural parity
3. Accessibility
4. Clean architecture
5. Maintainable code
6. Appropriate backend integration

## Frontend

- React
- JavaScript
- Vite
- Tailwind CSS

## Backend

- Node.js
- Express
- MongoDB
- Mongoose

## Rules

- Do not copy or lift source code from the reference website.
- Implement the UI independently based on the observed reference.
- Do not add unnecessary features.
- Keep components focused and reusable.
- Review AI-generated code before using it.
- Test interactive states and edge cases.
- Prefer simple solutions over unnecessary abstraction.

## Required Views

- Listing page
- Photo tour
- Lightbox

## Required Interactions

- Photo gallery
- Previous/next navigation
- Keyboard navigation
- Escape to close overlays
- Focus management
- Relevant hover and transition states
